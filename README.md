# 简记 · 轻量记账

纯前端记账 App，零依赖、数据存本地浏览器（localStorage），无需后端。

## 功能
- 记账：收入 / 支出，支出必选「消费类型（买了什么）」，网购可再选平台
- 统计：本月收支、分类占比、消费类型占比、网购平台分布
- 多端同步：生成 / 导入「同步码」合并数据（记录去重、分类取并集）
- 自定义：支出 / 收入分类、网购平台、消费类型均可增删；支持 CSV 导出

## 使用
直接用浏览器打开 `index.html` 即可；或访问 GitHub Pages 在线版。

## 数据说明
所有数据仅保存在你本机浏览器。换设备或清缓存前，请用「我的 → 导出 CSV」或「同步码」备份。
